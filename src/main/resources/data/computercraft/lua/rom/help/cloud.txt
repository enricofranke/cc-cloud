CC: Cloud shows your computers on a web dashboard (phone or desktop). Place a Cloud Uplink next to a computer, link it to a Cloud Mainframe with a Cloud Link Card, then right-click the mainframe for the URL and pairing code.

Quick start with the helper library:
local ui = require("cloud.ui")
local dash = ui.connect()
dash:title("Reactor")
local temp = dash:gauge("temp", "Temperature", {max=1200, unit="K", warn=900, crit=1100})
dash:button("scram", "SCRAM", {color="red", confirm=true, pin=true}, function(user) redstone.setOutput("back", true) end)
dash:every(1, function() temp:set(math.random(600, 1000)) end)
dash:run()

Examples: run "cloud-demo" (every widget) or "cloud-storage" (storage dashboard for an ME/RS Cloud Bridge).

Raw peripheral (local cloud = peripheral.find("cloud_uplink")):
cloud.setTitle(text)
cloud.page(id, title, {icon=})          pages/tabs; allows up to 64 widgets
cloud.group(id, title, {page=, cols=1..4})
cloud.button(id, label, {confirm, pin})
cloud.toggle(id, label, {value, confirm, pin})
cloud.slider(id, label, {min, max, step, value, unit, pin})
cloud.gauge(id, label, {min, max, unit, warn, crit, value})
cloud.label(id, text)
cloud.chart(id, label, {min, max, unit, points=60, interval=1, style="line"|"sparkline"})
cloud.progress(id, label, {min, max, unit, value})
cloud.indicator(id, label, {value=false, onColor, offColor})
cloud.select(id, label, {options={"low","mid","high"}, value})
cloud.number(id, label, {min, max, step, value, unit})
cloud.text(id, label, {maxLength=64, value, placeholder})
cloud.buttons(id, label, {options={"A","B","C"}})
cloud.itemSearch(id, label, {bridge="me_cloud_bridge_0", max})
cloud.watchlist(id, label, {bridge=...})
cloud.jobs(id, label, {bridge=...})
cloud.set(id, value)   cloud.setMany({id=value, ...})
cloud.remove(id)   cloud.clear()
cloud.alert(text, level)   cloud.notify(text, level)   level: info, warn, crit (max 1/s)
cloud.isOnline()   cloud.getClients()   cloud.getLastClientSeen()

Every widget also takes the layout options page, group, span (1-4), order (0-10000), color (cyan, green, yellow, red, gray) and icon (home bolt flame drop box fan lock warning gear chart star leaf heart cpu shield pick).

Events: os.pullEvent("cloud_action") returns "cloud_action", id, value, user, side. Buttons send true, toggles a boolean, sliders and number inputs a number, select and buttons the chosen option, text inputs a string. A craft started from an itemSearch widget sends a table {op="craft", name, count, jobId}.

Limits: ids are 1-32 characters of a-z, 0-9 and _. 32 widgets per uplink (64 with pages), titles and labels 48 characters, text values 256.

Cloud Bridges (ME / RS, need Applied Energistics 2 or Refined Storage): isConnected(), getEnergy(), getMaxEnergy(), getEnergyUsage(), getStorage(), listItems([filter], [limit]), findItems(query, [limit]), getItem(name), isCraftable(name), craft(name, count), getCraftingJobs(), cancelCraft(jobId), listFluids([limit]). An uplink placed directly on a bridge shows a ready-made Storage dashboard without any code.
