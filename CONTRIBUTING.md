# Contributing to CC: Cloud

Thanks for helping! Bug reports, mod integrations, translations, docs and Script Store scripts are all welcome.

- **Questions and ideas:** the [Discord](https://discord.gg/4fnQcvbzg6) (#help, #ideas) is the fastest way.
- **Bugs:** open an issue with the bug template (versions + an [mclo.gs](https://mclo.gs) log link).
- **Security issues:** never in public – see [SECURITY.md](SECURITY.md).
- **Bigger changes:** open an issue or ask on Discord first, so we can agree on the approach before you write code.
- **Script Store scripts:** follow [`store/CONTRIBUTING.md`](store/CONTRIBUTING.md).

## Development setup

Requirements: JDK 25 (Gradle downloads it if missing), Node.js 24, Git.

```bash
./gradlew build                                   # mod jar in build/libs/ + unit tests + handbook check
./gradlew runClient                               # dev client with CC: Tweaked
./gradlew runGameTestServer -PskipLoadTest        # GameTests (-PstorageMods for AE2/RS, -PintegrationMods for mods)
cd cloud && npx pnpm@10 install && npx pnpm@10 dev   # dashboard against a mock server
cd cloud && npm run typecheck && npx vitest run   # dashboard checks
cd cloud && npm run build                         # bundle the dashboard into the mod resources
```

More detail – icon export, screenshots, the handbook generator, CI – is in [`docs/BUILD.md`](docs/BUILD.md).

## Project layout

| Path | What |
| --- | --- |
| `src/main/java/ai/ezfox/cccloud/` | The mod: blocks, network, web server, integrations |
| `cloud/web/` | The dashboard (Preact PWA), built into `src/main/resources/cccloud_web/` |
| `cloud/web/src/docs/content/` | The bilingual docs (EN/DE); the in-game handbook is generated from them |
| `website/` | cccloud.dev (Astro) |
| `store/` | Script Store registry, validator and index builder |
| `discord-bot/` | The community Discord bot |
| `tools/` | Art generators, capture, showcase and helper scripts |
| `docs/` | Spec, security, hosting, build and compatibility notes |

## Guidelines

- **Match the surrounding code:** naming, comment density and idiom. Keep changes focused; one topic per pull request.
- **Tests:** add a unit test or a GameTest for game logic and a vitest for dashboard logic. CI (`build.yml`) must stay green.
- **Docs:** user-visible changes update the docs (`cloud/web/src/docs/content`, then `node tools/gen_handbook.ts`), and
  `CHANGELOG.md` under "Unreleased". Technical design goes into `docs/SPEC.md`, anything security-related into
  `docs/SECURITY.md`.
- **Art:** every texture of the mod is generated by `tools/gen_textures.py` in the CC: Tweaked look
  ([`STYLE_NOTES.md`](STYLE_NOTES.md)). Never commit Minecraft or other mods' textures – item icons are exported at
  build time.
- **Mod integrations:** stay optional. Use the existing integration patterns, never a hard dependency; see
  [`docs/COMPAT.md`](docs/COMPAT.md).
- **Translations:** the docs and the website are English and German; please keep both in sync, or say in the PR which
  language still needs an update.
