# Code of conduct

CC: Cloud follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
on GitHub, on the Discord server and everywhere else the project meets.

In short: be kind, be patient with newcomers, keep criticism about code and ideas, and no harassment of any kind.

Report unacceptable behaviour to a moderator on the [Discord](https://discord.gg/4fnQcvbzg6) or privately to the
maintainer through GitHub. Moderators may remove content and warn, mute or ban people who break these rules.
